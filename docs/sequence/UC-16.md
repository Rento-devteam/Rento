# UC-16 — Расчёт после возврата (settlement)

**Статус:** частично (поля settlement на Booking + cron retry)

```mermaid
sequenceDiagram
    participant WF as BookingsWorkflow
    participant DB as PostgreSQL
    participant Pay as Payment gateway
    participant Job as Scheduled job

    WF->>DB: COMPLETED, settlementStatus=PENDING
    WF->>Pay: capture rent + release deposit
    alt success
        Pay-->>WF: ok
        WF->>DB: settlementStatus=SETTLED, settledAt
    else fail
        Pay-->>WF: error
        WF->>DB: settlementStatus=FAILED
        Job->>DB: retry due bookings
        Job->>Pay: retry
    end
```

Отдельной таблицы `Transaction` нет — см. [state/Transaction.md](../state/Transaction.md).
