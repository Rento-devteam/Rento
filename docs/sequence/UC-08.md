# UC-08 — Календарь объявления (ручные блоки)

**Статус:** реализовано

```mermaid
sequenceDiagram
    actor Owner as Арендодатель
    participant WebApp as Frontend
    participant Cal as CalendarController
    participant DB as PostgreSQL

    Owner->>WebApp: Календарь объявления
    WebApp->>Cal: GET /listings/:id/calendar
    Cal->>DB: manual blocks + blocking bookings
    Cal-->>WebApp: занятые / свободные даты

    Owner->>WebApp: Выбор диапазона
    WebApp->>Cal: GET /listings/:id/dates/availability?start&end
    alt есть активные брони в диапазоне
        Cal-->>WebApp: conflict
    else свободно для ручного блока
        Owner->>WebApp: Заблокировать
        WebApp->>Cal: POST /listings/:id/calendar/block
        Cal->>DB: ListingManualCalendarBlock
    end

    Owner->>WebApp: Снять блок
    WebApp->>Cal: DELETE /listings/:id/calendar/block
    Cal->>DB: delete manual block
```

Автоблокировка дат при `POST /bookings` (CONFIRMED и др.) — через занятость в `Booking`, отдельного `notify_booking` API нет.
